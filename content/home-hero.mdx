---
title: A simple starter kit for Next.js with MDX
---

This is a simple starter kit that integrates Next.js with MDX using `next-mdx-remote`. You can find the complete source code on [GitHub](http://github.com/cyishere/nextjs-starter).

You can remove the default styling by simplely deleting `src/app/globals.css`, and there's no CSS class be using in this project.
